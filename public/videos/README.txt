VIDEO ASSET DIRECTORY
======================

Place the three MP4 video assets in this directory with the exact filenames:
1. skincare-ad.mp4
   -d:\Portfolio ad\Skincare.mp4
2. hask-conditioner-ad.mp4
   ->d:\Portfolio ad\Haircare.mp4
3. ocooker-blender-ad.mp4
   ->d:\Portfolio ad\blender.mp4

NOTE:
If any of these video files are not yet uploaded, the portfolio automatically detects their absence and renders a polished, editorial fallback interface displaying project specs, duration, format (9:16 vertical / 16:9), and creative brief details without breaking the layout.
